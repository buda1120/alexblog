四月的结束

我的博客名叫“四月日出”，我喜欢四月，April也给我特别的感觉，从小时候就喜欢四月，后来又听说一部动漫叫“四月是你的谎言”，越发觉得这个词有含义了。 四月，前期特别忙乱，精神压力到了极端，陷入了一段时间的忧郁之中。忧郁的时间里总是会想些悲伤的事情，例如死亡。我时而惧怕死亡，时而在脑中迎接死亡，但同时一直没能搞懂如何看待死亡。至今我仍然沉在大同去世的悲伤中，接触得越多，对于生与死的思考也越多，活着的意义在于什么，每天每天就这样重复着度过了吗，我能做些什么改变，这些改变会持久吗，会让未来的生活发生变化吗…这些总是让我陷入沉思。对于死亡，我知之甚少，至今接触到真实与深刻的死亡只有2次，第一次年纪太小根本没有参与感，只是看着大人们操办葬礼；第二次只觉得不真实，能够回忆起那2天的冷静与疲惫，旅途奔波的劳累、亲人的疲乏、一些固定的仪式安排消磨人的精力，分散开注意力，让死亡的伤痛在那特定的2天减淡了许多。然而，鉴于我的性格，悲伤来得缓慢持续得久，在平常的日子中总能突然变得悲伤起来，忧郁一直沉在心底，会偶尔浮出水面激起涟漪。 最近看了、听了一些关于死亡的说法。真的有灵魂存在吗，我觉得有但认为只会短暂存在，几个月或者1年后会消散。精神是持久的，只要你存在，保持着你想要表现的精神，无论时间如何流逝，它会一直在，留下的人也会持久地感受到。看了一个说法后，觉得分别在一定程度上也是一种死亡，是维度的原因，空间维度带来的隔离感更强。一次分别可能是再也不会相见，以后也不会得知Ta的任何消息，在我的世界里Ta们就如同死亡了一样，存在于另一个维度，与我的时空完全分隔的维度。宇宙如此奥妙，更高的维度、更大的空间也许存在，死亡或许只是离开了人所能观察到的、认知到的层面，是向更高的层面跳跃了。看到社媒，我更新了一点想法。以前看到死亡的消息我都只会说RIP，认为永隔了，是一种分割。这次却留意到许多人说的是：我们会再见面，意味着某一天我们会同时处于另一个不同于现在的维度，靠着我们的努力终会有见到面的时刻。这个概念让我对死亡有了不同的、更进一步的理解，哲学总会影响到我… 分别后的偶尔的再次见面，我又觉得世界多么奇妙，网络与信息让许久不见的人的最新状态保持同步，说出的新词语所有人都能理解，聊的天也是最新的内容，似乎时间没有带来变化，同步调的人总能无障碍地交流。最近发现物品总能让我联想的人和事，随便一个小东西，比如牙膏就能带我回忆道那天和同事第一次去商场购物的情形，任何东西，只要它确切的发生过一些事，就能让我联想到事情里的人物，陷入回忆，往事对我的影响还是这么大，几年了还是这样，这让我觉得或许几年后仍是这样。 心情复杂，悲伤是四月的基调，从头到尾，悲伤还远没到结束的时候，不知道会持续多久，我又能如何平衡这些情绪保持正常的生活状态。但愿是几个月。

纪念方大同

大同，在3.1日工作室发布消息公告大同于25/2/21去世，看到这则消息我很震惊，同时也有隐隐的悲伤。 第一次接触他可能是初高中的时候，那时我喜欢听_西城男孩_ 的 『Nothing’s gonna change my love for you』，用来学习英文，同时也觉得好听。过了一段时间，偶然听见大同翻唱的版本，婉转的声音深入我心。上大学后才正式持续地听他的歌，我爱听R&B的曲风，各个设备的各种播放器里都建了R&B的list，每每有空闲或是想要舒缓心情时，都会点开歌单戴上耳机隔绝外界。那时候是17-19年，大同的专辑都出了很多，我也因此能听到很多歌。最开始听的是『黑白』，记得有过很长一段时间没听R&B后，最先想要听的就是这首，歌词很吸引我。我最爱的是『爱爱爱』、『Love Song』和『枫叶做的风铃』。许多歌都会唱，但很少完整听过一张专辑，热门的曲目听得更多。 在疫情的后2年，我整个情绪都是低沉的状态，觉得世界上发生的事情都是灰暗的，没有一抹彩色出现在眼前。直到21年偶然听到大同发了新歌『面面』，听完觉得十分有趣，以前听网友调侃他不擅长写中文歌词，能一眼分辨出来是不是本人作词，哈哈，这首歌可以说是本人作词作曲。听完『面面』，才发现那段时间大同发过好几首新歌于是逐一来听。这些歌都给我带来了温暖，在阴沉的时间里听到了欢声笑语，帮我减轻了痛苦与压抑。特别是他为自己的童书绘本写的专辑，Amy是个可爱的小姑娘，也是friend，勇敢智慧，我的内心也受到了触动，会有Amy环绕在我周围的感觉，那几个小时会觉得春光无限好，真是美好的一天。 接着就是去年了，在他发布『才二十三』的后几天听了这首，大概听了两三遍，里面的歌词最令我印象深刻的是『上一次看 才二十三』，开头的几句写得奇怪『过去变成了现在 未来刚才来』似乎是时间倒转，回到了二十三。那时没有认真听，也没察觉到声音有些变化，并且以为是像以前一样发行的单曲，觉得挺不错。 再到3.1日，再听了他最后的专辑『梦想家』，有Jezz、R&B、Tango，又看了专辑的采访，他聊到自己的许多Idea，让我觉得他确实是个“音乐人”，有很认真、严谨地做音乐，所以能创作出这么多masterpiece。只是惋惜身体状况不好，没办法支撑未来的音乐梦。 最后引用一句歌词来缅怀大同『感谢你的出现 过去的往事就如烟…』RIP.

谈论近期新闻

最近一个月来发生了许多暴力的事情，新闻都是在封锁这些消息，而昨晚看了推特上的一些记录，很恐怖，甚至开始担心在身处街头时的个人安危，太可怕了。在我的印象中最早的一起是日本学生被刺一位女士见义勇为挡刀最后身亡，这件事引起了全平台媒体的报道，似乎有降半旗悼念那位女士，也有人在反思中国的仇恨教育。然而没过多久，在另一个地方的日本人学校，又有小学生被刺，这次没人来见义勇为，学生直接当场死亡了，再次登上新闻热榜。社会讨论的还是国家的仇日、对立等洗脑教育，谴责媒体的煽风点火，同时也有人说将日本人赶出中国这样的话。 后来事情发展得越发严重，事故的目标变为国人。首先是高架桥汽车被撞逆行，司机踩油门撞死了相向而来骑电动车和单车的人，行车记录仪的视频看着很惨烈。再就是11月初的珠海汽车冲进体育场，轧死不少无处可逃的中老年人。接着是大学生受不了学校和工厂的双面压榨，在学校暗夜埋伏刺伤学生，还留下遗书“要推动劳动法”。这些是死了2人以上的，其他的事件没有这么多受害者，但都是为了报复社会，无差别行凶，太可怕了，会让我想到之前流传的东北杀人的哪些事，全是街头随机杀人，无缘无故就被刺身亡，社会治安乱到不敢出门。 我觉得这些积怨是从疫情开始滋长的，封城、上门查核酸、转运、少粮食、假疫苗、缺药，解封后经济也没能明显好转，银行不让取钱赋红码、人口拐卖、楼市一蹶不振、股市打鸡血、青年人就业难、各种裁员失业、外卖员与保安冲突。这些事情几乎接触到了所有人，都被欺骗和打击着，一直压抑着情绪，终于趁乱爆发了。然而那些人只会伤害比他更弱小的，没有能耐去动真正压榨他们的人，懦夫！这些人自己安静的去死好了，何必拉上那么些无辜的人送命，简直是败类！ 这几天在看《疑犯追踪_Person of Interest_》美剧，在NY计算机监测每个人的活动，提前弹出会有危险的人的信息，主角们找到这个目标然后采取行动，尽量阻止危险的发生并保护目标。很贴切最近的现实，中国需要这样的机器，而且说不定每天跳出的数字会有几十个，无论是酝酿中的还是正在进行的，都会危害社会与他人的安全。 因为这些事，最近感到不安，觉得身处危险之中。

尝试新方式，重新部署Blog

用到的参考文档，按照遇到问题的顺序： dockerDocs：https://docs.docker.com/desktop/install/linux/ubuntu/ docker命令走代理获取镜像源（参考走代理部分）：https://blog.csdn.net/Lichen0196/article/details/137355517 阮一峰docker教程：https://www.ruanyifeng.com/blog/2018/02/docker-tutorial.html 一步到位wordpress：https://www.cnblogs.com/tdsj/p/16820590.html mysql旧数据迁移：https://blog.harumonia.moe/sql-frm-myi-myd-files/ 过了这么久，终于重新把博客部署了。自从电脑坏了修过、换了系统后，博客就再也无法启动了。趁着十一的几天休息，完成了这件事。 第一次部署是纯手工的方式，在Windows系统装了nginx、PHP环境，很久才弄出来大约花了2天的时间。这次用更接近新技术的工具–docker，省时省力，也不会有那么多错误，不过也花了1天。主要原因是第一次使用docker，完全不会，只因系统是Linux，手动装一些deb包很麻烦，命令行下载才是最快、最可靠不会出错的方式，感恩Linux。 最首先得一个困难就是Docker的资源库在中国被屏蔽了，想要的镜像完全没办法访问。真是出师未捷身先死，技术学习上也要面对政治障碍，可悲。装docker简单，直接apt获取，但访问资源却困难重重，看了网上的方法：要么换源，要么用代理。网络上提供的源都存在不稳定性，不知道那一天就面临被封锁。所以我选择了代理，研究了许久，在一片中文文章里学习到，如果本地配置好了代理，docker的网络直接设置为localhost就可以了，这样可以直连dockerhub拉取镜像资源。 拉取了mysql8和wordpress的镜像，配置、启动很艰难的完成了，最后数据库总是连不上，原来是localhost的问题，在docker里面mysql的ip地址不是121.0.0.1，而是需要通过inspect找出来的。这点耗费了近3小时，因为数据库连不上导致我反复重新配置实例，删完装，装好连不上又删。再就是迁移数据了，之前dump的不是sql文件，导致无法直接运行，需要用mysql5复制文件夹到数据库软件里展示，也花了不少时间。到最终大工告成已是第二天的下午了。 记录下期间提供帮助的文章和相关的指令 1.解决apt-get update的错误：在软件管理软件中，取消勾选对应出错的包，对于publickey出错的，解决办法 sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys xxxxxxxx 2.使用docker pull时出现404错误：Get "https://registry-1.docker.io/v2/": context deadline exceeded ，原因：dockerhub被ban，解决办法配置代理 $ /etc/systemd/system/docker.service.d/proxy.conf 写入 [service] Environment="HTTP_PROXY=localhost:7890" Environment="HTTPS_PROXY=localhost:7890" 3.装好docker后配置：使用非root用户管理docker sudo groupadd docker sudo usermod -aG docker $USER newgrp docker docker run hello-world 4.安装配置wordpress和数据库连接的关键点--数据库的ip地址 不能在宿主机上进入mysql，先进mysql的docker容器，再进数据库：docker exec -it mysql-cillian bash 查找容器的IP ：docker inspect mysql-cillian |grep 172 再进数据库： mysql -h 172.17.0.3 -uroot -p 5.迁移数据，使用mysql5.x，在mysql workbench中导出sql文件，重新导入mysql8.x中 INSERT INTO new_table_name SELECT * FROM old_table_name WHERE xxx=xxx
