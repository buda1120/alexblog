尝试新方式，重新部署Blog

用到的参考文档，按照遇到问题的顺序： dockerDocs：https://docs.docker.com/desktop/install/linux/ubuntu/ docker命令走代理获取镜像源（参考走代理部分）：https://blog.csdn.net/Lichen0196/article/details/137355517 阮一峰docker教程：https://www.ruanyifeng.com/blog/2018/02/docker-tutorial.html 一步到位wordpress：https://www.cnblogs.com/tdsj/p/16820590.html mysql旧数据迁移：https://blog.harumonia.moe/sql-frm-myi-myd-files/ 过了这么久，终于重新把博客部署了。自从电脑坏了修过、换了系统后，博客就再也无法启动了。趁着十一的几天休息，完成了这件事。 第一次部署是纯手工的方式，在Windows系统装了nginx、PHP环境，很久才弄出来大约花了2天的时间。这次用更接近新技术的工具–docker，省时省力，也不会有那么多错误，不过也花了1天。主要原因是第一次使用docker，完全不会，只因系统是Linux，手动装一些deb包很麻烦，命令行下载才是最快、最可靠不会出错的方式，感恩Linux。 最首先得一个困难就是Docker的资源库在中国被屏蔽了，想要的镜像完全没办法访问。真是出师未捷身先死，技术学习上也要面对政治障碍，可悲。装docker简单，直接apt获取，但访问资源却困难重重，看了网上的方法：要么换源，要么用代理。网络上提供的源都存在不稳定性，不知道那一天就面临被封锁。所以我选择了代理，研究了许久，在一片中文文章里学习到，如果本地配置好了代理，docker的网络直接设置为localhost就可以了，这样可以直连dockerhub拉取镜像资源。 拉取了mysql8和wordpress的镜像，配置、启动很艰难的完成了，最后数据库总是连不上，原来是localhost的问题，在docker里面mysql的ip地址不是121.0.0.1，而是需要通过inspect找出来的。这点耗费了近3小时，因为数据库连不上导致我反复重新配置实例，删完装，装好连不上又删。再就是迁移数据了，之前dump的不是sql文件，导致无法直接运行，需要用mysql5复制文件夹到数据库软件里展示，也花了不少时间。到最终大工告成已是第二天的下午了。 记录下期间提供帮助的文章和相关的指令 1.解决apt-get update的错误：在软件管理软件中，取消勾选对应出错的包，对于publickey出错的，解决办法 sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys xxxxxxxx 2.使用docker pull时出现404错误：Get "https://registry-1.docker.io/v2/": context deadline exceeded ，原因：dockerhub被ban，解决办法配置代理 $ /etc/systemd/system/docker.service.d/proxy.conf 写入 [service] Environment="HTTP_PROXY=localhost:7890" Environment="HTTPS_PROXY=localhost:7890" 3.装好docker后配置：使用非root用户管理docker sudo groupadd docker sudo usermod -aG docker $USER newgrp docker docker run hello-world 4.安装配置wordpress和数据库连接的关键点--数据库的ip地址 不能在宿主机上进入mysql，先进mysql的docker容器，再进数据库：docker exec -it mysql-cillian bash 查找容器的IP ：docker inspect mysql-cillian |grep 172 再进数据库： mysql -h 172.17.0.3 -uroot -p 5.迁移数据，使用mysql5.x，在mysql workbench中导出sql文件，重新导入mysql8.x中 INSERT INTO new_table_name SELECT * FROM old_table_name WHERE xxx=xxx

2024/7/6 六 晴天 搬到新家1周，有些累。房子是月底到期的，和中介发生了一些纠缠，心烦意乱的，整个人也是很疲惫。上班的状态，也要搬家整理。其中一天整日没吃东西，就喝了点水，体会到了近乎休克的感觉。这几天仍然有些许低血糖的征兆，会眼前一黑晕乎乎的，真的要注意身体健康。今天终于能休息一天了，睡了很久的觉，醒来觉得精神好了一些，似乎补上了这一周欠缺的睡眠，但还是有些疲惫，最近好好休养一下吧。 毕竟上班不是最累的，不需要怎么加班，每天工作8小时就可以了，还算能清闲一些。下班的时间才是需要好好规划的。自从24年春节后，我就没怎么详细地安排，这样过去了半年，一切都还和去年年底一样，似乎在工作中没学习到任何东西，下班时间也没补充知识，说着学英语、日语，结果一事无成，甚至英语也下降了许多，对自己有点失望啊。现在能回想起的学习时间只有去年的9月，认真的学了20天时间，学到的内容在工作中提供了一些帮助，很有用处。可是为何现在我没办法重新回到那样的状态呢，是工作耗尽了我的精力吗，还是我变得懒散了。 想着搬了新家，环境好了许多，那自然要重新开始我想做的事情了。看着这样上班没有尽头，参考同事，有些进来了1年还是做着助理的活儿，根本没有涉及到运营的内容中，关于付费、推品这些没有接触到。看看我呢，也是一样，身处于店铺职能中的底层，工作内容日复一日，每天都想着跳脱出来，却根本不付出努力，上班啊也没有空来提升，任务量就把时间占得满满了，一切都只有下班来做了。我应该改变生活习惯，把学习提上日程来！！！

近日找工作记录

开始着手写简历是2023.02.06（正月十六），再网上找了难看的模板，目标是软件测试。从去年四月开始我的求职目标就变成了测试，结果到年底也仅面试了1.5次（第二次只做了题，没通过就直接取消后续的面试了…），没什么经验，实战的项目也只有基础的一个，虽然后续学了接口测试、性能测试一类的软件，但没有项目的实践，靠这样的经历写简历根本不可能有人要。但是从2月到3月中旬我都在持续学习测试的内容，看论坛。结果就是现阶段软件行业很难过，即使是有2-5年经验开发&测试都很难找到面试机会，基本是1/100的面试与投递比，我这种款呢就更没有去处了，于是决定换赛道，因为我对测试的激情都比不上开发….如何能做得下去 3月中旬的时候看了数据分析的讨论，仍觉得数据分析适合自己，或者说是有吸引力的，因为偏技术（与数据挖掘有关系，也能使用到代码SQL、Python、Hadoop一些），不过大部分都是需要业务知识的，而我可以说什么都没有，所以迈出第一步，真正去做业务积攒经验，所以选择了做运营。运营这一类别，大致有3个类目：用户运营、内容运营、活动运营。我选择了“电商运营”，主要是内容运营，也包括了少许用户运营。不过以我的水平只能当助理一步步提升level，而助理的薪资可以说很少，大部分是3k~3.5k，所以大城市是没法去了，只能被迫选择武汉了。所以目标就是武汉的国内电商助理岗位。 目标选择好了，但是没有这一方面的经历，所以我赶忙在淘宝上注册了店铺，拟用一周的时间学习店铺的管理、上下架之类的。真的很耗费时间，随便弄一弄就好几个小时，选择商品真的很麻烦，选图片好看的、价格便宜的、类目清晰的，很繁琐，我大概做了5天，基本是会操作了。接下来就在牛客做了简历，很简短的内容也不多，随便就投出去了。看招聘软件上，还有挺多公司招无经验的，所以大概四五天后有了可能的面试，那天是周一。当晚我根本难以入睡，因为感觉到我正站在岔路口，似乎草率地做了决定，一直到清晨才听博客入睡。第二天我干脆强迫自己不去想这件事了，一直躺在客厅看电视，中途妈妈打了电话过来，问我工作的事，我告诉她有机会了但是没约面试，想要等到下周再行动。结果被一口否决，强烈地要求我周四就出门，约周五的面试。我没办法拒绝，因为我原本也有这个想法，只是认为有些仓促，一直摇摆不定。于是我当晚又辗转反侧，艰难入睡。周三收拾了家里，懒了几个小时就开始收拾行装了，开着电视陪伴着，东西装了一箱子，春夏秋冬压缩到26寸的行李箱。第二天被闹钟吵醒，朦胧地整理了一下，在十点多出了门，中间和吴爹打了个招呼，似乎有些尴尬，我倒是还好。 来到武汉并安定下来大概是3.30下午3点，第二天有2个面试，我大部分都只安排2个，感觉多了我会难受到一整天心情不好。住在关谷广场附近的小区里，虽说之前经常在这儿逛，但从未逛到环岛的另一侧去，就像是去了新环境一般，弯弯绕绕遇到了不少，甚至有时候会迷路。青旅简短地评价一下：男女混住，床上用品卫生条件差，睡着身上痒，洗漱之类的还可以，女生有专用的卫生间，总体很一般（或许我应该去软件上评价一下…）。周五八点多醒了，大约九点出门，做公交去光谷北辰里，第一次去，那里的高楼在一个园区里，风景很好，像小区又像商业园，有保安、门卫，有咖啡店、面包店、理发店，似乎还有居民带小孩过来消遣。公司不是很大，大约10个人，主做饰品，HR也挺好的，女性居多，大屏电脑。面试很简短，大约15min，没有录取。出来后我在周围的椅子上坐着刷手机，阳光很好温度也还没那么高，还有微风吹着，风景真的一绝。第二家是在光谷软件园，我曾多次路过那里，从没从岔路口拐过去过，去了才晓得环境有多差，特别是与上午的对比过后，尤其明显。甚至比金融港还要差得多，几乎没有公共休息的小公园，到处都是电驴，散步的路也特别窄。进了公司，比上一家规模还要小，大约6人，老板直接与员工大声交流该怎么做，他一个人带运营新手。面试很激进，要求比较高，需要“按能力”加班，连休息日都是“按能力”大小周或双休，要求的就是努力的人，几乎都会到8点多走。且做了一套逻辑面试题，里面有数理逻辑、计算题、博弈、数学、排序一类的，共10题100分，我做了近二十分钟吧，结果得了60分，老板说刚刚好…给了录取机会。面试完很累，回去休息了一会儿，充了个电后就出去玩了，我穿了毛衣+带绒卫衣，天呐超热！！找了商城洗手间脱下了毛衣，接着去了一家书店，居然是夹在饭馆的中间，是新华书店联盟的，进去坐了一会店内的空气都有一股油烟味，没多久就出来了。吃了油泼面套餐，面难吃，肉夹馍很一般。接着在手机上找到了另一家评分高的书店，居然是在商城人流量少的一栋，有2层，装修得很“网红”，天花板是镜面的，书架特别高大约2.5m，螺旋楼梯侧面也摆了书，一直沿着到天花板，不过店家做了假，大约摆了3~4层的真书，再高一点直接用画着书本的墙纸代替了。在里面待了2h，儿童区，看低年级的常识书，还挺有趣的。期间有个可爱的小男孩在店内拍照，感觉他有点累，因为后来他在我看书的对面拍照，拍完后叹了一口气，似乎拍摄终于接近尾声了。 周末没有面试，周六姐姐有考试，在武昌，我坐公交过去挺近的，所以约她考完试一起玩。去户部巷、江滩玩了几小时，中午太热了，她换了短袖穿，我仍穿着带绒卫衣。中途在人民医院门口歇了，风吹我的帽子，我用两只手用力地捂住了帽子，结果戳到了坐我很近的姐姐的眼皮，直接红肿了且毛细血管戳破了渗出红色，真的很抱歉，我之前也觉得太用力了，没想到会伤人，很sorry。晚上在中商超市买了酸奶和菠萝，被菠萝毒了，吃完舌头发麻失去感觉。以及酸奶在单独吃的情况下建议风味酸奶，纯酪要配水果一起才好吃。周日睡到9点起床收拾，因为要移动到江汉区了。早上躺在床上定了一家旅馆，虽然价格会稍高一些，但至少不会睡觉痒…并且有公交车是从光谷直达汉口站的，我也不想拖着箱子过地铁安检，公交就方便多了。原本刚出小区就能赶上那趟公交的，但道路识别失误刚好晚了几秒钟，于是在烈日下等了13分钟下一趟才来。车上也很多人，司机师傅开得猛，大箱子在座位周围摇来晃去的，全程我都用手扶着生怕跑走撞到哪里了。这趟公交是跨江的，让我想到了国产剧《reset》，听说故事原型就是武汉的跨江公交，不知道是不是这趟了。不过车子跨江的时候，大家都很安静，大部分人都望着窗外欣赏风景，我也如此，即使看过好几次仍然被吸引。旅馆是个小单间，床还挺大，独卫不过喷头不好调节，总是会被烫到。走廊尽头有一个大阳台，老板把床单被套晾在那儿，我也把衣服晾在那儿，风特别大，可能因为这两天一直下雨吧。衣服吹了一天仍然潮，大致算干了，收回来后用吹风彻底烘干。 大暴雨 周一天气预报说是暴风雨，早上约了10点的面试，在一座公寓楼里，可以步行从旅馆过去。早起了，天气还可以，没有下雨，不过走到一半就下起了小雨，鞋也打湿了。于是放弃了面试，去了附近的商城，结果是我熟悉的路，感到很开心，工作日商城也很少人，我在洗手间用鼓风机吹了鞋子，又在那儿坐了很久。刚好爸妈当天在深圳游玩，在微信群里发旅游图，我闲着无聊就评价和指导他们的拍照技术，有趣又难得。在商场吃了一盒水果，算是简单的午饭，到12点就移动到了第二家要面试的公司附近，在便利店，原本只是打算歇脚&躲雨，后来又饿了，买了根玉米吃。找公司也迂回婉转，去了地址上的楼层，结果公司名字不对，我有下楼在周围寻找另一栋楼，后来重新进去问了楼下的前台，才知道就是那家公司，只是名字是母公司的。公司挺大的，一平层，工作的人数大约5080，在饭厅面试，一个销售总监，男，挺随和的，聊了30min，最后觉得我能通过面试。面试期间，外面瓢泼大雨，外加打雷闪电，天空乌压压的，像晚上七八点一样。面试完外面仍下着雨，没有变小，风把雨吹起来，我称之为“雨雾”，地面鼓着许多大泡泡。等了一会儿雨小了，于是约了上午爽约的那家，决定4点多过去。也是步行，大约30min到了。不是居民楼，是小型办公区。很高的楼，大约4050层，那家公司面积不算小，但显得很拥挤，因为员工很多。有两层，不过竟然连真正的部门分区都没有，HR挤在狭小的缝隙里，老板一人在大声教导员工该做些什么，一层大约30人，二层6个工位，显得宽敞多了。老板则是拥有靠窗的独立办公室，古色古香的桌子，摆放着精美的茶具，可以看窗外的风景，而员工就处在这个封闭的环境中。当时我只想到了“老板和打工的”，面试这么多回，这是我第一次见办公室如此拥挤且员工像奴隶一般工作的。天哪！而且上班的要求是从早上八点多一直到晚上九点，期间午休1h，晚上6：30下班，但得留下来学习，7点开始一直到9点，没有时间吃完饭，只能吃点零食填肚子。我很震惊！面试结束后，走回来，结果5点多下暴雨，于是停在路边等雨停，大约强度持续了20min，后面小一些了我就直接冲出去了。最终，两只鞋都湿了，裤子、上衣也湿了，在旅馆附近买了晚餐，迅速回来洗澡换了干衣服。路上听武汉电台，主播提醒着市民下雨天要保持身体和换洗衣物的干燥，建议在办公室备干净的鞋袜，雨天的衣服用吹风或机器烘干，避免皮肤病。还说袜子比内裤干净，衣物混在一起扔进洗衣机洗也是可以的，不会细菌交叉感染之类的。晚上也一直在下雨，明天就是阴天了，也有面试，需要坐车过去，希望顺利！：）
