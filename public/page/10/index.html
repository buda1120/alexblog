投简历有感

 今天是我开始投简历的第20天，在9.1我投了第一份简历，不完美瑕疵很多，但是用了内推，也算是进入了笔试。这就几天陆陆续续做了笔试投了简历，估计也有快10家了，很累。现在又在找公司，每天在招聘网站上花3小时，改简历写信息、投递。即便如此，投递了部分公司邮件也不会发送，什么消息也没有，就很难受，不知道自己是否经过了初筛。这两天，压力巨大，并且晚上也睡不着，心理上不仅是求职应聘的是，还有一些过去没消化的创伤，没到深夜安静的时候，思绪就会飘过来，想到这些事我会伤心流泪，这样就根本无法入睡。这个状态持续了一个多星期了吧，我觉得我或许需要一些心理治疗了，这也太难受了，没晚都是凌晨一两点才入睡，我就得心脏都优点承受不住了。 求职的压力太大了，我似乎每天都在诉说，当然只是对自己，没有对别人倾诉太多。在求职的同时还需要学习，Java 唉我很晚才确定自己要学的是Java，七月中旬吧，小学期结束之后。之后就开始看java的视频，其实也没学多久一个月，感觉是学了一些东西，至少JavaSE的基础知识了解了，但是高级的线程、框架、数据结构之类的就不太会。到了九月真正的秋招开始了，如临大敌，感觉自己穿着一副破烂的盔甲上了战场，可能会死得很难看。现在我就是躲在边上，找一些钢铁修修补补，自己做一个有点防御能力的盔甲吧，感觉像是死里逃生，最后能否有一线生机就看我的盔甲最终能不能保护我到战争结束了。

Java笔试感受

今天参加了第一场笔试，恒生java工程师。总体的感觉还是正常，有会的也有不会的。两套卷，一个是技术，一个是综合。 技术篇分为两个部分，选择题和大题。选择题考了java基础、设计模式、计网、linux指令、数据库。大题是一个数据库、一个编程题和一个算法题。数据库因为最近在学，也在经常写语句所以不算难，东西也都复习到了，就是还有内容没学完就也有不会的，但是考前突击了下，恰好碰到了。编程题和算法题，思路大致都有，但是编码就有些许困难。编译器没有提示功能，写一些复杂的我就忘了。java语言的工地也不是很强。需要提高java的编码能力了！ 综合篇也是两部分，一个是个人性格测评，一个是类似 “行测” 的选择题。性格测评就没什么好说的了，逻辑能力测试就有一点过了。15道选择题，求实找规律、初中的计算题、普通的逻辑问题。很没趣味又有点烦人。因为找不出规律或者算不出答案就开始心慌。 整个测试一共是2个小时，坐在凳子上，很累。明天还有笔试，我似乎找到了自己能力的不足之处，需要花时间和精力去补足。虽然内容很多，但是只要不停止学习就一定能有收获，所以要抓紧时间，学习不停歇！加油，希望秋招顺利，收到offer！

C语言(一)

复习C语言，记录一下重要的知识点，参考书为《C Primer Plus 第六版》 一、初识C语言 产生：1972年，贝尔实验室的Dannis Ritch 和 Ken Thompson 在开发UNIX操作系统的时候设计了C语言。在过去40年里，C语言已成为最重要、最流行的编程语言之一。 C语言的优点：高效性， 可移植性，强大而灵活，面向程序员 缺点：涉及指针的编程错误难以察觉；有很多运算符，可以写出复杂的‘晦涩难懂的代码（可以看看 国际C语言混乱代码大赛IOCCC，很有趣） 应用范围：小型计算机，PC，大型机；C++也是以C语言为基础。 高级编程语言与编译器： 计算机编程语言有高级语言和低级语言，像C、JAVA、Pascal等比较接近自然语言的就是高级语言，汇编语言等用指令或01代码来表示的就是低级语言。高级语言更接近人类，低级语言更靠近机器。当然用两种类型的语言写的程序执行所需要的时间也是不同的，高级语言花费的时间要长一些。计算机执行一个C/C++程序需要经过编译、链接然后才能执行。 程序执行的步骤 GNU编译器： GNU项目始于1987年，是一个开发大量免费软件的集合（GNU means “GNU’s Not UNIX” 即GNU不是UNIX ）。GNU编译器集合（也被称为GCC，其中包含GCC C编译器）是该项目的产品之一。用 gcc 命令便可调用GCC C编译器。许多使用 gcc 的系统都用 cc 作为 gcc 的别名。 二、C语言概述 典型的C程序： # include　//预处理指令 int main (void)　//main()总是第一个被调用的函数 function a( )　//函数是C程序的构造块，将函数中包含语句 ...

汇编原理的学习

从7月底开始了汇编的学习，之前有上过汇编的课，但是老师讲的没有怎么理解，实验也不会写，所以就入手了王爽老师的《汇编原理（第三版）》，开始了自学。 我遇到的第一个难题是汇编环境的配置。我的电脑是win10 64位系统，不支持cmd的debug、edit一类的，所以我下载了虚拟机，在虚拟机上装了一个xp系统，这个cmd可以支持debug，然后就开始了学习。（后面发现还需要别的.exe，所以又下载了另一个软件…） 虚拟机的下载和安装： 我用的是VMware workstation pro 14.0 for windows, 在官网上下载的，地址：https://my.vmware.com/en/web/vmware/info/slug/desktop_end_user_computing/vmware_workstation_pro/15_0，安装到最后需要密钥，自己去百度一下或者csdn找一找 然后新建虚拟机，在我的计算机中就会出现xp的虚拟机，单击它在右侧会有“开启此虚拟机”的选项，单击就开始运行了，打开cmd就能运行debug了，开始汇编的学习~
